# Marché+ — Prototype

Prototype de plateforme de gestion d'appels d'offres (démo : AO-2026-014).
Application statique, un seul fichier `index.html` (HTML/CSS/JS inline, état de démo en `localStorage`).

## Lancer en local
Ouvrir `index.html` dans un navigateur, ou :
```bash
python3 -m http.server 8000
```

## Déploiement
Publié automatiquement sur GitHub Pages à chaque push sur `main`
(workflow `.github/workflows/pages.yml`). Activer une fois : *Settings → Pages → Source : GitHub Actions*.
